# Online-Property-Tax-Payment-System
Online Property Tax Payment System – College Project

**Description**

Developed an Online Property Tax Payment System as an academic project to simplify and digitise the property tax management and payment process.

The system is designed to help citizens manage property-related information, calculate applicable property taxes, make payments, and access payment records. It also provides administrative functionality for managing property records, verifying information, monitoring transactions, and handling tax-related operations.

**Key Features**
- User authentication and role-based access.
- Property registration and management.
- Property tax calculation.
- Online and offline payment management.
- Payment receipt generation.
- Property verification and approval.
- Grievance management.
- Administrative dashboard and reporting.

**Technology Stack**

Version 1: React.js, Vite, Node.js, Express.js, MongoDB and Mongoose.

Version 2: PHP, MySQL, HTML, CSS and JavaScript.

**Project Type:** Academic / Full-Stack Web Development Project

**Objective:** To develop a digital platform that makes property tax administration more accessible, organised and efficient.
